## Назначение расширения

AI-Helper для разметки читает выбранный пользователем текст на разрешённых страницах Argilla, отправляет его выбранному пользователем AI-провайдеру и показывает результат автоматической разметки в браузере.

Расширение не запускает обработку текста без действия пользователя, кроме случаев, когда пользователь сам включил автоматический режим.

## Какие данные обрабатываются

### Текст веб-страницы

При запуске обработки расширение извлекает текст из выбранных пользователем элементов страницы. Этот текст, а также выбранный пользователем промпт и системная инструкция отправляются на AI-сервис, выбранный в настройках расширения.

Поддерживаемые встроенные сервисы включают Groq, Google Gemini, Cerebras, Mistral, OpenRouter и DeepSeek. Пользователь также может указать собственный OpenAI-совместимый HTTPS API.

Ответ AI показывается пользователю в расширении. Разработчик расширения не получает этот текст напрямую.

### Настройки и ключи

В локальном хранилище Chrome сохраняются:

- настройки AI-провайдеров и их API-ключи;
- пользовательские промпты;
- настройки интерфейса и горячих клавиш;
- список сайтов, которым пользователь разрешил доступ;
- настройки общей библиотеки промптов, включая имя пользователя и код доступа, если пользователь использует эту функцию;
- случайный идентификатор установки, необходимый для работы общей библиотеки промптов.

Эти данные используются для работы расширения и не отправляются разработчику сами по себе. API-ключи передаются только соответствующему AI-сервису при выполнении запроса пользователя.

### Общая библиотека промптов и Supabase

Если пользователь подключает общую библиотеку промптов, запросы отправляются в Supabase Edge Function проекта разработчика.

В зависимости от выполненного действия Supabase может получить:

- случайный идентификатор установки;
- имя, указанное пользователем для публикаций;
- код доступа для проверки права доступа;
- название и текст промпта при ручной публикации;
- идентификатор и название промпта при добавлении промпта в локальную библиотеку;
- технические события `active` и `prompt_added` для агрегированной статистики.

Код доступа используется для проверки роли и не сохраняется в таблицах статистики. Текст веб-страниц и API-ключи AI-провайдеров в Supabase не отправляются.

## Цели обработки

Данные используются только для:

1. выполнения автоматической разметки текста;
2. сохранения пользовательских настроек и промптов;
3. работы общей библиотеки промптов;
4. поддержания и измерения работы общей библиотеки.

Данные не используются для рекламы, профилирования, продажи, маркетинга или отслеживания истории посещений.

## Передача данных третьим сторонам

Текст страницы передаётся только выбранному пользователем AI-провайдеру, потому что это необходимо для получения результата разметки.

Данные общей библиотеки передаются Supabase, потому что это необходимо для публикации, загрузки и удаления общих промптов.

Использование данных AI-провайдерами и Supabase регулируется их собственными политиками конфиденциальности. Пользователь должен самостоятельно ознакомиться с условиями выбранного сервиса.

Разработчик не продаёт пользовательские данные, не использует их для персонализированной рекламы и не предоставляет их людям для чтения, за исключением случаев, предусмотренных законом или необходимых для безопасности сервиса.

## Хранение и удаление

Локальные данные хранятся в профиле Chrome до тех пор, пока пользователь не очистит данные расширения в настройках Chrome или не удалит расширение.

Опубликованные промпты хранятся в общей библиотеке до их удаления пользователем, имеющим право на удаление, либо администратором проекта.

Технические события общей библиотеки хранятся в Supabase для статистики использования. Пользователь может обратиться к разработчику по указанному выше адресу с запросом на удаление связанных с ним данных. Запрос может потребовать подтверждения принадлежности данных.

## Безопасность

Передача данных между расширением и удалёнными сервисами выполняется по HTTPS. Расширение не запрашивает и не обрабатывает пароли от сайтов, cookies, историю браузера, данные банковских карт или координаты местоположения.

Пользователь отвечает за безопасность введённых им API-ключей и кодов доступа и не должен передавать их другим людям.

Данные не используются для рекламы, продажи, профилирования или несвязанных целей.
